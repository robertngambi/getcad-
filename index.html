Flagship Product

Smart Prepaid Water Meter
Overview

Revolutionary IoT-enabled water metering built for utility challenges, with multiple modes, dual-app control, and real-time interaction.


The Pre-paid Water Meter with modern electronic devices that measures water flow, displays consumption data on an LCD, uploads data to cloud servers via GSM, automatically shuts off water when units are depleted, and connects via Bluetooth to a mobile application through which users or water customers are able to see their units remaining or bills, buy units, be able to turn ON or OFF manually.
Not only that, it serves as an intelligent node in a comprehensive water distribution network. It transcends basic prepaid functionality by offering multiple operational modes, dual-app control, and real-time utility-customer interaction. The system empowers utilities with unprecedented remote control and data-driven decision-making, while providing customers with flexibility, transparency, and control over their water usage and expenditure. It is a holistic solution designed to maximize revenue assurance, optimize operational efficiency, and enhance customer satisfaction through adaptive service models.

Hardware Core (Meter End):

Precision Flow Sensor & Metering Body: Measures water volume with Class C accuracy. Solenoid (or Motor) Shut-Off Valve: The physical actuator for remote and automatic flow control. Advanced Microcontroller Unit (MCU): The onboard computer that executes the core firmware. Its critical new function is to seamlessly switch between multiple, configurable operation modes (Auto, On-Service, Periodic) as dictated by the utility admin or customer request. Dual Communication Modules: GSM/GPRS for constant cloud connectivity to the utility server, and Bluetooth Low Energy (BLE) for direct customer app interaction. LCD Display & User Interface: Shows real-time data, active mode, credit, and warnings.

Software Ecosystem (Dual-App Platform), the GetCAD Water Management App:

Utility Admin Application (Web/ Utility Dashboard): This is the utility's command center. Installed at headquarters and regional offices, it provides a real-time map and dashboard of all deployed meters.

This meter is still under development.
